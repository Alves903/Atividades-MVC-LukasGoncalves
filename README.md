## Objetivo

Repositório criado para armazenar as atividades práticas de ASP.NET Core MVC desenvolvidas durante as aulas.

Os exercícios utilizam:

- ASP.NET Core MVC
- C#
- Razor
- Models
- Views
- Controllers
- Rotas
- Listas e dados em memória
- Regras de negócio
- Git e GitHub

## Exercícios

### 01 - Escola
Aplicação simples para apresentar informações de uma escola, cursos e contato.

### 02 - Academia
Aplicação com páginas de musculação, cardio e planos.

### 03 - Cinema
Sistema para apresentar filmes em cartaz e valores de ingressos.

### 04 - Restaurante
Aplicação para apresentar cardápio, bebidas e informações de contato.

### 05 - Hotel
Sistema para apresentar quartos, serviços e informações do hotel.

### 06 - Cadastro de Alunos
Aplicação utilizando Model e lista em memória para exibir alunos e seus detalhes.

### 07 - Catálogo de Produtos
Sistema para apresentar produtos, estoque e produtos disponíveis.

### 08 - Biblioteca
Aplicação para apresentar livros e identificar quais estão disponíveis para empréstimo.

### 09 - Clínica Veterinária
Sistema para apresentar animais cadastrados e realizar filtros entre cachorros e gatos.

### 10 - Loja de Eletrônicos
Catálogo de eletrônicos com filtros por estoque, categoria e preço.

### 11 - Sistema de Notas
Sistema para calcular a média dos alunos e classificar como aprovado, recuperação ou reprovado.

### 12 - Sistema de Estoque
Aplicação para controle de estoque, produtos esgotados, estoque baixo e alertas de reposição.

### 13 - Sistema de Pedidos
Sistema para visualizar pedidos, calcular valores e filtrar pedidos por status.

### 14 - Sistema de Cursos
Aplicação para apresentar cursos, vagas disponíveis e modalidades online ou presencial.

### 15 - Sistema de Cadastro de Funcionários
Sistema para visualizar funcionários, situação, departamento, faixa salarial e informações em um dashboard.

## Como executar

1. Abra a pasta do exercício desejado.
2. Abra o projeto no Visual Studio.
3. Execute o projeto.
4. Acesse as páginas utilizando o menu da aplicação ou pelas rotas configuradas.

## Observação

Os exercícios utilizam dados armazenados em memória, sem utilização de banco de dados.
